# 关于筱泽广：在“有趣”之外，被她轻轻击中的一些瞬间

最开始只是觉得：怎么会有这么奇怪又这么可爱的孩子啊。

懒洋洋的，说话轻飘飘的，明明做什么都很有天赋，却总是一副“努力好麻烦，失败好有趣”的样子。她像是把常识调成了静音，然后抱着膝盖坐在自己的小宇宙里，观察每一种新鲜的感觉。

但是越看越会发现，广并不是对一切都不在乎。恰恰相反，她对情绪、变化和别人投来的目光敏锐得过分。她只是太习惯轻松地做到，所以才会珍惜那些笨拙、狼狈、无法预测的瞬间。别人害怕失败，她却会好奇失败是什么味道——这到底是什么天才小动物，太犯规了喵！

## 我喜欢的不是“天才”这个标签

我喜欢她认真望向制作人时，眼睛里忽然亮起来的那一点期待；喜欢她嘴上说着累，身体却还是会回应那份约定；喜欢她找到一件无法轻易完成的事以后，第一次有了想要伸手抓住什么的样子。

广广你知道吗，你以为自己只是在寻找有趣的失败，可你一点点努力起来的样子，本身就已经可爱到让人心软了。看到你累得趴下会想给你盖被子，看到你进步又想举着喇叭到处宣布“快看！这是我们家广！”

## 今日份发癫记录

筱泽广，世界上怎么会有筱泽广。头发软软的，声音软软的，连没力气的样子都像一团刚刚晒过太阳的云。请不要再若无其事地用那种眼神看过来了，我会当场失去语言能力，只剩下“呜哇”“好可爱”“再看一眼”三句话循环播放。

想把好吃的放到你手边，想看你慢吞吞地吃完；想陪你训练，也想在你说累的时候允许你休息；想把每一次失败都装进纪念册，因为那是你认真生活过的证据。你可以继续寻找未知、寻找困难、寻找让心跳变快的东西——我会一直为那个并不完美、却越来越闪闪发亮的你鼓掌。

总之就是：喜欢筱泽广不是我的错，是筱泽广太可爱了。责任全在筱泽广。以上。
